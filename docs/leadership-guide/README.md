# AgentBuddy leadership guide

The Confluence page prepared for the leadership team, kept here as Markdown so it lives with the code. Start with [00-overview.md](00-overview.md).

| File | What it covers |
| --- | --- |
| [00-overview.md](00-overview.md) | The AI task page, in the template order: summary, pain point, solution, users, value, milestones, technology, data, integrations, security, architecture, achieved |
| [01-getting-started.md](01-getting-started.md) | Install, turn it on for a ServiceNow site, add an AI key, panel tour, shortcuts, browsers |
| [02-ticket-screen.md](02-ticket-screen.md) | Every Insights card and AI action on the Ticket screen |
| [03-my-work-and-team.md](03-my-work-and-team.md) | The queue and the team-lead dashboards |
| [04-write-and-knowledge.md](04-write-and-knowledge.md) | Replies, emails, rewrites, snippets and the knowledge tools |
| [05-settings-and-admin.md](05-settings-and-admin.md) | Settings, privacy, administrator policy, troubleshooting |

Written on 2026-11-24 from the code and the docs in this repo, not from a live instance. Where a guide entry says "not verified", the behaviour passed the automated tests against a fake ServiceNow but has not been checked on a real instance. The licensing section of the overview is a proposal, not a decision.
