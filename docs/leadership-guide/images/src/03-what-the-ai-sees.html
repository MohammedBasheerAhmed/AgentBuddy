What the AI sees, and what it does not
An example with invented sample data. Names and emails are swapped for placeholders before the text leaves the browser.
1
In ServiceNow
The ticket as written
VPN keeps disconnecting for Abel Tuter (abel.tuter@example.com). It drops every few minutes. Please call Abel back today.
→
2
What leaves the browser
Masked. The person previews it
VPN keeps disconnecting for [PERSON_1] ([EMAIL_1]). It drops every few minutes. Please call [PERSON_1] back today.
→
3
What the AI sends back
It only ever saw placeholders
Hi [PERSON_1], sorry about the VPN drops. Please reset your VPN password in the self-service portal and tell us if it still drops.
→
4
What the person sees
Real values restored on the device
Hi Abel, sorry about the VPN drops. Please reset your VPN password in the self-service portal and tell us if it still drops.
Only this part goes to the AI endpoint
The person is in control
They see exactly what will be sent before pressing send, and can mask more.
Secrets never come back
A password, card number or ID number the AI repeats is not put back into the answer.
Strict mode for sensitive work
HR cases and security records use stricter masking, set by the organisation.
