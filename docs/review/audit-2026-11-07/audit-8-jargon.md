## (b) Style guide that follows

1. Say "ticket" for anything an agent works on (incident, request, task, case). Name the type only when it matters: "incident", "requested item", "catalog task", "HR case". Never "record" for a ticket and never "{table} records".
2. Never show a table or column name. One shared map from table to display label (today there are three: `plainAccess.js` WORDS, `mywork/tables.js` KNOWN_TABLES, `reports/engine/constants.js` REPORT_TABLES); unknown table = "this kind of ticket" or "this information".
3. Say "you", never "your user". Say "your role" not "access rule/ACL/permission".
4. Say "ServiceNow site" (or just "ServiceNow"), never "instance". Say "signed out", never "session expired/ended".
5. Say "AI key" and "AI service" (not API key, provider, endpoint, model unless in Settings > AI).
6. Never show HTTP codes, "Table API", "query", "filter" (as a database word), "column", "field history", "journal", "token", "JSON". Put them behind a "Copy details" button.
7. Every error says what happened in one plain clause, then one next step: "Try again", "Sign in again", "Open Settings", or "Ask your administrator".
8. One person for escalation: "your administrator" (Agent Buddy settings) and "your ServiceNow admin" (access); drop "IT team".
9. Policy/config sentences (disabledFeatures, orgFormats, deployment guide, CSP) go to an admin-only page or a "Copy for your administrator" button; the agent sees one line.
10. "Masked" stays only with its gloss ("personal details hidden"); use "hidden" in titles.
11. One word per thing: article (not KB, not knowledge article), ticket type (not table/kind), site (not instance), sign in (not log in), AI limit (not token cap).
12. Sentences that call a thing "incident" must be checked against RITM, SCTASK, HR and CSM tickets.
13. A sentence that blames ("Your user cannot read") becomes a fact plus action ("You can't see X with your role. Ask your ServiceNow admin if you need it.").
14. Engine notes written outside `t()` must be routed through `tm()` keys or a code (`reason`), so the Arabic panel is not half English.
15. Arabic: choose one word each for site, AI service, limit; keep the numbers of an HTTP code out of Arabic as well.
