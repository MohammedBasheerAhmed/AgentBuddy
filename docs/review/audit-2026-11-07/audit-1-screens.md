## 3. Common root causes

1. There is no shared `tableLabel`/`kindLabel`. Seven independent partial maps exist (section 4); `src/context/kinds.js` has slugs but no label function. The slug `kind` itself is never printed (checked), it is the TABLE that leaks (`record.table`, `pack.table`, `newRecord.table`, `access[].source`, `${table}` in notes).
2. The context engine writes English sentences with the table name inside (`Your user cannot read ${table}.` and 12 more in access.js, related.js, chat.js, checks.js, domain.js, insights.js), and the panel then tries to repair them with a regex (plainNote) that knows 37 names and skips every one-word name. Fix: carry `{source, status, reason}` only, word it in the panel with a label.
3. `disp()` falls back to the stored value, so an empty display value becomes a sys_id (D1).
4. Pass-through of error text (`plainError`) shows our own diagnostic wording to people (E1).
5. Arabic: sentences are English and only the head is translated (I1, I3, I4, R1), `a group you cannot see` (I7), `language=en` (I7).
